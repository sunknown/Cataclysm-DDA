# Death does not end the session; no clients does

A character's death no longer ends the party. The corpse stays where it fell,
the connected player gets the ordinary character-creation flow as a popup, and
their replacement appears next to the party. There is no spectator mode: a dead
player either creates a replacement or leaves. The session ends only when no
clients remain connected, not when no living characters remain. This replaces
§8.4 of the parent design, where any death and any disconnect ended the session.
